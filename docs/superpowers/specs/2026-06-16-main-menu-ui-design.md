# 主菜单 UI 设计方案

## 目标

改进主菜单布局，解决当前所有元素居中堆叠导致左右空间浪费的问题，采用《球球大作战》官方风格的左右分区布局。

## 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 布局方式 | 左右分区 | 利用横向空间，视觉平衡，便于扩展 |
| 左侧内容 | 基础玩家信息 | 头像+昵称+段位+赛季，数据层已就绪 |
| 右侧内容 | 大按钮+小按钮混排 | 主次分明，"开始游戏"视觉突出 |
| 背景 | 动态星空 | 增加层次感，与球主题呼应 |
| 标题风格 | 渐变描边 | 与深色背景协调，有立体感 |

## 详细规格

### 1. 背景 - 动态星空

**基础背景色**: `#0a0a1a`（比当前 `#1a1a2e` 更深）

**星点系统**:
- 数量: 100-150 个随机星点
- 大小: 1-3px，随机分配
- 颜色: 白色为主，少量淡蓝 `#88ccff`、淡黄 `#ffeeaa`
- 闪烁: 正弦波控制透明度（周期 1-3 秒，各星点不同相位）
- 位置: 整个屏幕随机分布，窗口 resize 时重新生成

**流星效果**:
- 触发: 每 3-8 秒随机生成一颗
- 方向: 从右上角划向左下角
- 长度: 50-100px 拖尾
- 动画: 持续 0.5-1 秒后消失
- 颜色: 白色渐变到透明

**漂浮球**:
- 保留现有 20 个漂浮球，降低透明度 alpha: 40 → 15
- 作为远景装饰，不干扰星空主视觉

### 2. 左侧面板 - 玩家信息卡片

**尺寸**: 固定宽度 280px，高度自适应（约 320px）

**位置**: 左侧边距 40px，垂直居中

**样式**:
- 背景: `rgba(15,20,40,0.85)` 半透明深色
- 边框: `rgba(255,255,255,0.1)` 1px
- 圆角: 16px
- 内边距: 20px

**内容结构**:

| 元素 | 规格 |
|------|------|
| 头像占位 | 圆形 80x80，渐变背景 `#1a1a2e → #2a2a4e`，中央显示默认图标（如 ★ 或球图标） |
| 昵称输入 | 保持现有风格，宽度 240px |
| 段位徽章 | 段位名称（如"青铜 III"）+ 对应颜色 + ELO 数值 |
| ELO 进度条 | 高度 12px，圆角 6px，背景 `#222`，填充为段位渐变色 |
| 进度文字 | 如"距白银还需 200 ELO" |
| 赛季信息 | 赛季 ID + 剩余天数，淡灰色 |

**间距**:
- 头像与昵称: 15px
- 昵称与段位: 20px
- 段位各元素: 8px
- 段位与赛季: 15px

### 3. 右侧区域 - 功能入口

**位置**: 右侧边距 40px，垂直居中

**标题**:
- 文字: "球球大作战"
- 字号: 52px
- 效果: 渐变描边（蓝 `#4fc3f7` → 紫 `#ba68c8` → 粉 `#f48fb1`）
- 外发光: 微弱扩散光晕（半径 2-3px，alpha 30）
- 副标题: "AGAR.IO CLONE"，16px，灰色 `#888`

**开始游戏按钮**:
- 尺寸: 280x56（保持现有）
- 样式: 渐变背景 `#e74c3c → #f39c12`，圆角 28px
- 悬停: 轻微放大（scale 1.05）+ 阴影加深 + 背景渐变变亮
- 按下: 缩小（scale 0.98）+ 渐变变暗

**次要按钮网格**:
- 布局: 2x2 网格
- 尺寸: 每个 120x36
- 间距: 12px
- 按钮列表: 设置、记录、段位、成就
- 样式: 半透明背景 + 边框 + 圆角，悬停变亮
- 图标: 每个按钮带小图标占位（可选实现）

### 4. 动画效果

**入场动画**:
- 左侧面板: 从左滑入（translate -50px → 0）+ 淡入（opacity 0 → 1），持续 300ms
- 右侧区域: 从右滑入（translate +50px → 0）+ 淡入，持续 300ms
- 错开: 左侧先开始，右侧延迟 100ms

**持续动画**:
- 星点闪烁: 每帧更新透明度 `alpha = baseAlpha * (0.5 + 0.5 * sin(time * speed + phase))`
- 流星: 独立 QTimer 或每帧检查是否需要生成新流星
- 按钮悬停: QPropertyAnimation 控制 scale 和 shadow

| 文件 | 改动 |

## 数据依赖

- 段位/ELO: 从 `DatabaseManager` 查询 `player_profile` 表（已有）
- 赛季: 从 `SeasonManager` 获取（已有）
- 无需新增数据层

## 验收标准

1. 左右分区布局清晰，左右两侧面板不重叠
2. 星空背景有闪烁星点和流星效果
3. 标题有渐变描边效果
4. 开始游戏按钮悬停有放大动画
5. 段位进度条颜色与段位匹配
6. 窗口 resize 时星点重新分布，布局自适应
7. 所有原有功能（打开设置、记录、段位、成就、模式选择）正常工作
