## 二、刺球变种（Wiki有，当前游戏无）

Wiki描述了17种刺球变种，以下是可在当前游戏中实现的：

### 建议实现的刺球类型

1. **普通刺球** (已实现) - 绿色，基础类型
2. **爆裂刺球** - 红色，吃后分身更大更不规则，杀伤力更强
3. **大刺球** - 体积更大，需更大球体才能吃，增重≥600
4. **毒刺球** - 红色，吃后不仅分裂还爆出大量孢子，总质量减少约1/8

### 刺球生成机制
- 游戏开始时生成一定数量刺球
- 当数量低于"最小刺球数量"时，立即随机生成新刺球
- 自由模式最小30个普通刺球

## 六、入坑指南关键信息

### 体重上限
- 单个球最大体重分：**40000**
- 理论最大总质量：40000 × 16 = **640000** 体重分
- 超过上限后无法继续增加质量

### 吞噬规则
- 队友之间大球可以吃小球（合作），但小球是最后一个球时不会吞噬
- 生化模式中同队伍不能互相吞噬

### 死亡与复活
- 大多数模式中玩家可以**无限次复活**
- 复活后质量回到初始值

### 段位系统（Wiki最新版）
| 段位 | 说明 |

| 青铜 | 基础段位 |
| 白银 | |

| 大师 I/II/III | |
| 王者 I/II/III | |
| 超神 | 最高段位 |

⚠️ Wiki段位与当前实现有差异：Wiki有8个大段位（含超神），当前实现有7个大段位（青铜→王者，每级3小段）。建议后续对齐。

### 刺球数量
- 自由模式最小**30个**普通刺球（当前实现20个）

### 彩豆数量
- 普通小彩豆数量一般为**3000**（当前实现2000个）
