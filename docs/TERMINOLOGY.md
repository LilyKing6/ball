## 1. 游戏概述

**球球大作战** 是一款大球吃小球的竞技游戏。

- **目标**：吃彩豆和孢子成长，吞噬其他玩家，成为本局最大的球球
- **核心循环**：吃 → 变大 → 吞噬 → 更大 → 登顶排行榜
- **游戏模式**：单人（对抗AI）或联机（对抗真人）

你的球球初始质量只有 10，非常小。通过吃地图上的彩豆慢慢长大，质量够了就可以分裂追击或吞噬其他小球。但小心——比你大的球球也在盯着你。

## 2. 实体术语

### 2.1 球球（Cell）

> 玩家的基本单位，一个圆形细胞。

| 属性 | 说明 |
|------|------|
| 初始质量 | 10 |
| 初始半径 | ≈12.6（公式：`4 × √质量`） |
| 最大数量 | 一个玩家最多拥有 16 个球球（通过分裂） |
| 外观 | 彩色渐变圆形，带光晕和高光 |

**新手提示**：刚出生时你的球球很小，先吃彩豆长大。质量越大，球球越大，但移动也越慢。

---

### 2.2 彩豆（Food）

> 地图上随机散布的小圆点，是球球的主要食物。

| 属性 | 说明 |
|------|------|
| 质量 | 1 |
| 半径 | 3 |
| 数量 | 约 2000 个 |
| 刷新 | 被吃后自动在随机位置补充 |
| 外观 | 各种颜色的小圆点 |

**新手提示**：彩豆是新手期最好的食物。吃一个只加 1 质量，但积少成多。优先吃密集区域的彩豆。

---

### 2.3 刺球（Virus）

> 绿色尖刺球，地图上的危险障碍物。

| 属性 | 说明 |
|------|------|
| 质量 | 100 |
| 半径 | ≈40 |
| 数量 | 约 20 个 |
| 触发条件 | 球球质量 > 110 触碰时 |
| 触发效果 | 球球被强制分裂成多个小球 |
| 安全条件 | 球球质量 < 110 可安全穿过 |

**新手提示**：
- 质量小于 110 时，刺球对你无害，可以直接穿过
- 质量大于 110 时，碰到刺球会被强制分裂，非常危险
- 被大球追时可以躲到刺球后面——大球不敢碰
- 可以向刺球吐孢子，使其向最近的玩家方向弹射

---

### 2.4 孢子（Spore）

> 玩家按 E 键吐出的质量球，可被任何球球吃掉。

| 属性 | 说明 |
|------|------|
| 质量 | 14 |
| 半径 | ≈15 |
| 吐出消耗 | 自身减少 14 质量 |
| 吐出条件 | 自身质量 ≥ 24 |
| 吐出冷却 | 0.1 秒 |
| 飞行速度 | 400 单位/秒 |
| 外观 | 橙色小圆球 |

**新手提示**：
- 孢子是快速成长的途径——吃一个孢子等于吃 14 个彩豆
- 吐孢子可以喂给队友（联机模式）
- 向刺球吐孢子可以引爆刺球，攻击附近的大球
- 被大球追时可以吐孢子引诱对方转向

---

### 2.5 分身（Split Cell）

> 按 Space 分裂产生的新球球。

| 属性 | 说明 |
|------|------|
| 分裂条件 | 当前球球质量 ≥ 36 |
| 分裂效果 | 质量均分，各得一半 |
| 分裂冷却 | 0.5 秒 |
| 合并冷却 | 分裂后 30 秒内不会合并 |
| 合并条件 | 30 秒后，两球距离 < 半径之和 × 0.6 |
| 最大数量 | 一个玩家最多 16 个球球 |

**新手提示**：
- 分裂后两个球球各自独立移动，都跟随鼠标方向
- 分裂后 30 秒内两球不会合并，即使重叠也不会
- 30 秒后，两球靠近时会自动合并恢复成一个
- 分裂主要用于追击比自己小的球——分裂后一半质量飞出去吃掉对方

## 3. 操作术语

### 3.1 分裂（Split）

| 项目 | 说明 |
|------|------|
| 按键 | Space |
| 方向 | 沿鼠标方向射出 |
| 条件 | 质量 ≥ 36，球球数 < 16 |
| 效果 | 当前球球一分为二，质量均分 |
| 冷却 | 0.5 秒 |

**什么时候分裂？**
- 追击小球：分裂一半质量飞出去吃对方
- 逃生：向远离敌人的方向分裂，快速拉开距离
- 快速吃彩豆：分裂后覆盖更大面积

---

### 3.2 吐球（Eject）

| 项目 | 说明 |
|------|------|
| 按键 | E |
| 方向 | 沿鼠标方向射出 |
| 条件 | 质量 ≥ 24 |
| 效果 | 自身减少 14 质量，吐出一个孢子 |
| 冷却 | 0.1 秒 |

**什么时候吐球？**
- 喂队友：联机时把孢子吐给队友吃
- 引爆刺球：向刺球吐孢子使其弹射
- 诱敌：被追时吐孢子引诱对手转向

---

### 3.3 吞噬（Devour）

| 项目 | 说明 |
|------|------|
| 触发 | 自动 |
| 条件 | 大球覆盖小球 50% 以上，且大球质量 > 小球质量 × 1.1 |
| 效果 | 小球被消灭，大球获得小球全部质量 |

**新手提示**：
- 你的球球比对方大 10% 以上才能吞噬对方
- 球球越大越容易吞噬，但也越慢
- 分裂后的小球质量减半，更容易被吞噬——分裂有风险

---

### 3.4 合并（Merge）

| 项目 | 说明 |
|------|------|
| 触发 | 自动 |
| 条件 | 分裂后 30 秒，两球距离 < 半径之和 × 0.6 |
| 效果 | 两球合并，质量相加 |

**新手提示**：
- 分裂后 30 秒内，即使两球重叠也不会合并
- 30 秒后，靠近时自动合并
- 合并后球球变大，速度变慢

## 4. 属性术语

### 4.1 质量（Mass）

球球的"体重"，决定大小和速度。

| 质量 | 半径 | 速度 |
|------|------|------|
| 10 | ≈12.6 | ≈95 |
| 36 | ≈24 | ≈50 |
| 100 | ≈40 | ≈30 |
| 500 | ≈89 | ≈13 |
| 1000 | ≈126 | ≈9.5 |

**公式**：
- 半径 = `4 × √质量`
- 速度 = `300 / √质量`

---

### 4.2 视野（View）

相机缩放级别。质量越大，视野越广，能看到更远的地方。

| 质量 | 可见范围（1280px窗口） |
|------|----------------------|
| 10 | ≈430 单位 |
| 100 | ≈1350 单位 |
| 1000 | ≈2100 单位 |

**公式**：`zoom = 1 / √(质量 / 20)`

## 5. 系统术语

### 5.1 段位（Rank）

7 级段位系统，基于 ELO 分评定。

| 段位 | ELO 范围 | 颜色 |
|------|---------|------|
| 青铜 | 0 - 799 | #CD7F32 |
| 白银 | 800 - 1199 | #C0C0C0 |
| 黄金 | 1200 - 1599 | #FFD700 |
| 铂金 | 1600 - 1999 | #E5E4E2 |
| 钻石 | 2000 - 2499 | #B9F2FF |
| 大师 | 2500 - 2999 | #FF4500 |
| 王者 | 3000+ | #FF0000 |

每级再分 I / II / III 三个子级。

---

### 5.2 赛季（Season）

- 每赛季 30 天
- 赛季结束 ELO 软重置：`新ELO = 1500 + (当前ELO - 1500) × 0.5`
- 赛季奖励：专属皮肤、称号

---

### 5.3 排行榜（Leaderboard）

实时显示本局前 10 名玩家及其质量。你的排名变化时会有箭头提示。
